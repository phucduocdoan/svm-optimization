# 10 — Nguồn hình minh họa và giấy phép

## Hình tự tạo trong project

Các hình dưới đây được dựng riêng cho project bằng SVG. Không phụ thuộc hotlink tới website bên ngoài.

| File | Nội dung | Ghi chú |
|---|---|---|
| `images/roadmap_horizontal.svg` | Roadmap 4 chặng | Mô hình hóa → biến đổi toán → giải tối ưu → thực nghiệm |
| `images/svm_geometry.svg` | Hình học SVM | Điểm và tọa độ giả lập để giải thích hyperplane/margin |
| `images/soft_margin_toy.svg` | Soft-margin | Dữ liệu tổng hợp 2D |
| `images/experiment_pipeline.svg` | Pipeline thực nghiệm | Nhánh SVC và SMO dùng cùng tập test |
| `images/architecture_layers.svg` | Kiến trúc source code | Phân tách module theo trách nhiệm |
| `images/smo_pair_update.svg` | Một vòng SMO | Cập nhật cặp alpha và giữ ràng buộc |

Các ảnh minh họa khái niệm không được trình bày như kết quả thực nghiệm trên Banknote. Kết quả thực nghiệm chỉ lấy từ các script trong `experiments/`.

## Dataset

- Banknote Authentication: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/267/banknote+authentication), Volker Lohweg (2012), DOI [10.24432/C55P57](https://doi.org/10.24432/C55P57), giấy phép CC BY 4.0.
